アシスト労務　修正手順（2026-11-09）
「休暇管理」に、お休み予定のカレンダー表示を追加

1. 何が変わるか

「休暇管理」の「これからのお休み予定」が、カレンダーと一覧の2つで見られるようになります。右上のボタンで切りかえます（選んだほうは、次に開いたときも覚えています。はじめは「カレンダー」です）。

機能内容
月のカレンダー日付ごとに人数が出ます。多い日ほど色が濃くなります（1人＝うすいオレンジ、2〜3人、4〜5人＝オレンジ、6人以上＝赤）。◀ ▶ で月を動かし、「今日」で戻れます。
現場名の表示日付のマスに、お休みの方が入っている現場名が出ます。同じ現場で2人休むと「×2」。現場ごとに色の点が付きます。1つのマスに5現場まで出て、それ以上は「ほか○現場」です。スマホは幅がせまいので人数だけです。
日付を押すとカレンダーの下に、その日の方が現場ごとに出ます（区分・理由・代わりの方・決裁の状態つき）。
絞り込み「全員／大阪／鳥取」と、「現場」のプルダウンで絞れます。
月の集計「この月の休み○件」「いちばん多い日」「決裁待ち○件」。
休みの日の色土日と祝日（振替休日・国民の休日をふくむ）に色が付き、祝日名も出ます。
決裁待ちの目印決裁待ちの方がいる現場名のうしろに「？」が付きます。
一覧これまでの「日付順」の一覧です。各人のとなりに、エリアのかわりに現場名が出ます。
現場名はどこから来るか
休み申請にはエリアしか入っていないので、従業員名簿の「就業場所（現場）」を引いて表示します。就業場所が空の方は「（現場の登録なし）」と出ます。名簿の就業場所を直すと、カレンダーの表示も直ります。
気をつけてほしいこと
・「否決」「取り消し」になった休みは出しません。
・過去の日付も、月を戻せばカレンダーで見られます（うすい表示）。これまでの「過去のお休み（これまでの記録）」カードは、そのままです。
・決裁は、これまでどおり下の「決裁待ちの休暇申請」からできます。

3. GitHubの更新手順

  1. ブラウザで GitHub のリポジトリ assist-roumu を開きます。（github.com/hminfokeiri-hue/assist-roumu）
  2. ファイル一覧の上のほうの 「Add file」 → 「Upload files」 を押します。
  3. お渡しした assist-roumu.html を枠にドラッグ＆ドロップします。ファイル名は assist-roumu.html のままにしてください。
  4. 下の緑のボタン 「Commit changes」 を押します。
  5. 1〜2分待ちます。

4. 反映されたかの確認

  1. アシスト労務を Ctrl + Shift + R で読みこみなおします。（反映されないときは、URLの末尾に ?v=20261109 を付けて開きます）
  2. 左上に 「更新: 2026-11-09」 と出ていれば反映ずみです。
  3. 管理側にログインして「休暇管理」を開き、「お休み予定」にカレンダーが出ているか確認してください。
  4. お休みのある日を押して、その日の方が現場ごとに出るか確認してください。「現場」のプルダウンで、現場が絞れるかも見てください。
